# Pixabay Image Search

## Image Search Application

A web application for searching and browsing images using the Pixabay API.

## Features

- 🔎 Image search
- 📄 Pagination
- ⏳ Loading indicator
- 🖼️ Responsive image gallery
- 🔍 Full-size image preview
- 📜 Smooth scrolling
- 🔔 User notifications
- ⚡ Asynchronous requests with async/await

## Technologies

- HTML
- CSS
- JavaScript
- Vite
- Axios
- Pixabay API
- SimpleLightbox
- iziToast
